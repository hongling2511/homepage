## Self-Test Q&A

<details>
<summary>❓ What's the SDK's core design principle?</summary>

Give agents computer access via terminal, using the same tools humans use.

</details>

<details>
<summary>❓ Why is Bash the most powerful?</summary>

General + Composable + Store results + Dynamic scripts + Reuse existing software

</details>

<details>
<summary>❓ Two main benefits of subagents?</summary>

1. Parallelization
2. Isolated context, return only key info

</details>

<details>
<summary>❓ How to choose verification methods?</summary>

- Code → Rules check (TypeScript/ESLint)
- UI → Visual feedback (screenshots)
- Subjective → LLM as judge (use carefully)

</details>
